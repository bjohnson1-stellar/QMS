# Welcome to the QMS Second Brain

This vault is the central knowledge base for the **Quality Management System (QMS)** development project.

## Getting Started

1. **Start here:** [[Home]] — Dashboard with module status and dependency graph
2. **Browse modules:** [[Module Index]] — All 11 QMS modules at a glance
3. **Understand architecture:** [[Architecture Overview]] — System design and data flows
4. **Install plugins:** [[Plugin Setup Guide]] — Recommended Obsidian plugins

## Vault Structure

| Folder | Purpose |
|--------|---------|
| `00-Dashboard` | Home page, indexes, Dataview dashboards |
| `01-QMS-Modules` | One doc per module (core, welding, projects, etc.) |
| `02-CLI-Commands` | CLI command reference (populate as needed) |
| `03-Architecture` | ADRs, system diagrams, design docs |
| `04-API-Endpoints` | REST API documentation |
| `05-Database` | Table documentation, schema overview |
| `06-Dev-Journal` | Daily development notes |
| `07-Troubleshooting` | Known issues and solutions |
| `08-References` | Plugin guides, external links |
| `Templates` | Note templates for each type |
| `Attachments` | Images, diagrams, exports |

## How to Use This Vault

- **Creating notes:** Use `Ctrl+N` then apply a template (`Alt+E` with Templater)
- **Linking:** Type `[[` to create links between notes
- **Searching:** `Ctrl+Shift+F` for vault-wide search
- **Graph view:** `Ctrl+G` to visualize connections
- **Daily journal:** Click the calendar icon or use `Ctrl+P` → "Open today's daily note"
